# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest release on [GitHub Releases](https://github.com/plynko/walkmark-desktop/releases) | Yes |
| Older tags | Best effort |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security problems.**

Use [GitHub private vulnerability reporting](https://github.com/plynko/walkmark-desktop/security/advisories/new) and include steps to reproduce, impact, and affected versions.

We aim to acknowledge reports within a few business days and will coordinate disclosure once a fix is ready.

## Scope

- Walkmark desktop app (this repository)
- Official installers published from this repository’s release workflow

## Out of scope

- Misconfiguration of third-party AI providers or API keys you supply
- Social engineering
- Issues in unsupported or modified builds
